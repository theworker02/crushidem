# crushidem

Crush timestamps and idem durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/crushidem/

## Install / run

```bash
git clone https://github.com/theworker02/crushidem.git
cd crushidem
node src/cli.js
node --test
```
